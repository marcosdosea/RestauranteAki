# RestauranteAki

## Descrição

O **RestauranteAki** é um sistema desenvolvido para gerenciar pagamentos personalizados por consumo em restaurantes. Este projeto visa atender as necessidades específicas dos usuários, abordando problemas recorrentes em estabelecimentos gastronômicos e propondo soluções eficientes através de tecnologia.

## Objetivo

Analisar, coletar e definir as necessidades dos usuários do software RestauranteAki. O sistema foi concebido com o propósito de fornecer uma experiência de pagamento mais prática e personalizada, integrando o consumo dos clientes diretamente à conta individual ou da mesa.

## Tecnologias Utilizadas

- **Back-end:** C# com .NET
- **Front-end:** JavaScript, HTML, CSS, Razor Pages

## Funcionalidades

- Criação e gerenciamento de pedidos por mesa ou cliente individual
- Atualização automática da conta conforme o consumo
- Cancelamento e alteração de pedidos com base no status da cozinha
- Interface amigável para garçons e clientes
